# Deep Learning Fundamentals

Building intuition for deep learning — from perceptrons to transformers.
Not just training models. Understanding why they work.

---

## Why This Repo?

NLP and LLM systems are built on deep learning.
This repo documents the journey from fundamentals to modern architectures.
Every concept is implemented from scratch before using a library.
